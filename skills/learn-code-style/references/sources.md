# Source History

Last substantive review: 2026-08-31.

- [PEP 8](https://peps.python.org/pep-0008/) supports project-local
  consistency taking precedence over generic Python convention and illustrates
  the local-versus-default distinction. Other languages require their own
  authoritative guides.

For every external guide, retain its title, publisher, canonical URL,
version/date, retrieval date, extracted convention, project applicability, and
limits. Preserve superseded entries and explain interpretation changes.
