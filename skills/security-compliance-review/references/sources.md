# Source History

Last substantive review: 2026-08-31.

- [ISO/IEC 27001:2022](https://www.iso.org/standard/27001) supports risk-based
  ISMS ownership, evidence, review, and improvement; this skill cannot certify
  conformity. Amendment 1:2024 remains current context.
- [ISO/IEC 27017:2026](https://www.iso.org/standard/27017) supports cloud shared
  responsibility. It superseded the 2015 edition in July 2026; the earlier
  “replacement expected” interpretation is superseded as of 2026-08-31.
- [AICPA SOC 2 resources](https://www.aicpa-cima.com/topic/audit-assurance/audit-and-assurance-greater-than-soc-2/)
  support the Trust Services Criteria map; only an appropriate practitioner
  examination produces a SOC 2 report.
- [CMMI](https://cmmiinstitute.com/improve-performance) supports repeatability,
  ownership, measurement, and improvement, not an appraisal claim.
- [NIST SP 800-218 SSDF 1.1](https://csrc.nist.gov/pubs/sp/800/218/final)
  supports lifecycle secure-development practices.
- [OWASP Excessive Agency](https://genai.owasp.org/llmrisk/llm062025-excessive-agency/)
  supports least privilege and approval for high-impact actions.
- [OWASP Agentic Top 10](https://genai.owasp.org/2025/12/09/owasp-top-10-for-agentic-applications-the-benchmark-for-agentic-security-in-the-age-of-autonomous-ai/),
  [AgentDojo](https://arxiv.org/abs/2406.13352), and
  [CaMeL](https://arxiv.org/abs/2503.18813) support agentic threat vocabulary,
  adversarial evaluation, and deterministic control boundaries; none is a
  complete defense or universal benchmark.

For consequential claims, retain publisher, URL, version/date, retrieval date,
finding, relevance, limits, and immutable identifier. Preserve superseded
entries and explain interpretation changes.
