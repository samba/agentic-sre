# Source History

Last substantive review: 2026-08-31.

- [SPDX](https://spdx.dev/use/overview/) supports interoperable component and
  license metadata; an SPDX document alone proves neither completeness nor
  legal acceptability.
- [OpenSSF Scorecard](https://openssf.org/projects/scorecard/) provides
  repeatable security signals; a score is only one contextual input.
- [SLSA v1.2](https://slsa.dev/spec/v1.2/) supports provenance and artifact
  verification; do not infer a SLSA level from isolated controls.
- [NIST SP 800-218 SSDF 1.1](https://csrc.nist.gov/pubs/sp/800/218/final)
  supports secure production and vulnerability response.

For consequential claims, retain publisher, URL, version/date, retrieval date,
finding, relevance, limits, and immutable identifier. Preserve superseded
entries and explain interpretation changes.
