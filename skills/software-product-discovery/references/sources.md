# Source History

Last substantive review: 2026-08-31.

- [ISO 9241-210:2019](https://www.iso.org/standard/77520.html) supports users,
  tasks, context, iterative evaluation, and whole-experience design. It does
  not establish conformity or replace user evidence.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) supports treating web
  accessibility as a requirement and testable outcome; use corresponding
  authoritative guidance for other platforms.

For a consequential claim, record publisher, canonical URL, version/date,
retrieval date, finding, relevance, limits, and immutable identifier when
practical. Preserve a superseded entry with its replacement and interpretation
change rather than rewriting history.
